Architecture & Implementation

Asynchronous Fetch & Async/Await

Implements modern JavaScript async/await syntax to execute non-blocking HTTP requests, validating network responses with response.ok and handling potential network failures cleanly with try/catch.

  • Fetch API
  • async / await
  • Promises

Dual REST API Pipeline

Chains Open-Meteo's Geocoding API to resolve arbitrary city names into latitude/longitude coordinates, passing resolved metadata directly to the Weather Forecast API for accurate real-time metrics.

  • Open-Meteo Geocoding
  • Forecast API
  • JSON Pipelines

Defensive Error Handling

Provides explicit feedback for empty inputs, unresolved city queries, malformed payloads, and network disconnection, completely eliminating silent unhandled promise rejections or dashboard crashes.

  • Fault Tolerance
  • Input Validation
  • User Feedback

WCAG AA & Theme Integration

Incorporates ARIA live regions for screen readers, semantic form controls, visible focus indicators, and full CSS variable reuse for seamless light and dark mode switching.

  • ARIA Live Regions
  • Semantic HTML5
  • Dark Mode Tokens
